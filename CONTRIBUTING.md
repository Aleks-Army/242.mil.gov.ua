# Як долучитися

Дякуємо за інтерес до концепту! Це **неофіційний прототип**, тож найцінніші внески — дизайн, тексти-приклади, доступність і швидкість.

## Правила безпеки

- ❌ Жодних персональних даних військовослужбовців, їхніх рідних чи працівників.
- ❌ Жодної службової, чутливої чи непублічної інформації (локації, графіки, склад підрозділів).
- ✅ Лише вигаданий або вже публічний контент із позначкою «приклад».

## Процес

1. Створіть issue з описом ідеї або проблеми.
2. Зробіть fork і гілку, внесіть зміни.
3. Перевірте локально: `python3 -m http.server 8000` → http://localhost:8000, телефон і комп’ютер.
4. Відкрийте pull request зі скріншотами «до / після».

## Стиль

- Без фреймворків і збірки: HTML, CSS (`assets/style.css`), vanilla JS (`assets/app.js`).
- Семантична розмітка, видимий фокус, контраст за WCAG 2.2 AA.
- Українська — основна мова, англійська — для розділу партнерів.
